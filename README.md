Made for Harmony by y4my4my4m (https://github.com/y4my4my4m/harmony)

## How to use

```
download install.sh
go to the folder install.sh is in in whatever terminal you use
chmod +x install.sh
./install.sh
```



This installer is very simple (And only works on Arch sorry).
It pulls the requirements with pacman, installs itself into /home/user/.local/share/ as Harmony.
## Features
Not relying on chrome/whatever browser. Just webkit (yippie), less RAM usage (not a lot though lol)
When you "close" it it closes to taskbar icons (in KDE plasma 6. I haven't tried others), you left click it to either open it or quit it entirely
The single install script also comes with the icon
